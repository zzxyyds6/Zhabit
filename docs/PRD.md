# Zhabit 习惯打卡 App 需求文档

> 版本：v0.4（草稿）  
> 产品名：**Zhabit**  
> 参考项目：[InlitX/streak](https://github.com/InlitX/streak/tree/main)（Flutter，GPLv3）— 唯一参考  
> 文档状态：待评审

---

## 1. 背景与目标

做一个**极简、离线、无广告**的习惯打卡工具，帮助用户：

- 把每天要做的事变成"一键打卡"的动作；
- 清楚看到自己坚持了多少天、哪些天做了、哪些天没做；
- 把一次性的小事（短期记录）快速记下来、做完就消失。

### 1.1 参考对象

本产品**只参考**开源项目 **Streak**，以它的功能结构为蓝本做裁剪和本地化：

| 参考项目 | 借鉴点 |
|---|---|
| [Streak](https://github.com/InlitX/streak/tree/main) | 习惯类型、打卡交互、统计视图、提醒与桌面小部件、数据备份、云同步思路 |

### 1.2 许可证提示

Streak 使用 **GPLv3**。如果直接复用其代码，衍生项目也必须以 GPL 兼容方式开源；如果只是参考功能思路、自行实现，则不受此约束。本需求按"自行实现"来规划。

---

## 2. 产品定位与核心原则

| 原则 | 说明 |
|---|---|
| 一键即用 | 打开 App 首屏就是"今天要做的事"，打卡不超过一次点击 |
| 本地优先 | 打卡、浏览、提醒在无网时完全可用；云同步只做加密备份与恢复，不是运行前提 |
| 简洁不堆功能 | 首屏只有"长期习惯"和"短期记录"两个区块 |
| 可解释 | 每个统计（连续天数、完成率）用户都能看懂怎么算的 |
| 可带走 | 数据随时可以导出成普通文件，用户自己保管 |

## 3. 功能需求

### 3.0 功能总览与优先级

| 优先级 | 含义 | 范围 |
|---|---|---|
| P0 | MVP，第一个可用版本 | 添加习惯、一键打卡、短期记录、基础提醒 |
| P1 | 第二阶段 | 日历看板、统计、主题个性化、桌面小部件 |
| P2 | 锦上添花 | 专注计时、导入其他 App 数据、应用锁等 |

---

### 3.1 长期习惯

#### 3.1.1 习惯类型

首版（P0）只做**普通习惯**；定量、避免型在后续版本支持（与 Streak 对齐）：

| 类型 | 含义 | 示例 | 优先级 |
|---|---|---|---|
| 普通习惯 | 每天要做的事 | 睡前阅读、喝水 8 杯 | P0 |
| 定量习惯 | 有数量目标，单位自定义 | 喝水 ≥ 8 杯、跑步 ≥ 3 公里 | P1 |
| 避免型习惯 | 尽量**不做**的事，做了算"破戒" | 不熬夜刷手机、不吃零食 | P2 |

#### 3.1.2 打卡交互（P0）

- 首屏列表中，每个未完成的习惯显示一个明显的"打卡"按钮；
- 点击后按钮从亮色变为已完成态（绿色 + 打钩），当天记录生效；
- 点击已完成按钮可撤销当天打卡；
- 定量习惯打卡时弹出数量输入（默认推荐值，可一键确认）（P1）；
- 避免型习惯：当天默认"成功"，标记"破戒"才算失败（P2）。

#### 3.1.3 打卡清单（P1）

- 一个习惯可以拆成若干子步骤（如"睡前阅读 = 读 20 分钟 + 记笔记"）；
- 所有子步骤勾完才算当天完成；
- 计时器/打卡过程中可以不离开当前页勾选子步骤（P2）。

#### 3.1.4 频率与日程（P0）

每个习惯可选择以下一种：

- 每天；
- 每周 X 次（如每周 3 次）；
- 指定星期几（如一、三、五）；
- 每 N 天一次（如每 2 天）。

#### 3.1.5 补打卡（P0）

- 点击任意历史日期（最多回溯 30 天）可以补做或取消；
- 补打卡会重新计算连续天数。

#### 3.1.6 看板与统计（P0 基础 / P1 完整）

**P0（首版必须有）：**

- 每个习惯卡片上显示：
  - 连续天数（当前 streak）；
  - 最近 7 天的打卡小圆点（做了/没做）；
  - 频率说明（每天 / 每周 3 次）。
- 点开习惯，可以看到一个**月历视图**，已做/未做/未来一目了然。

**P1：**

- GitHub 风格的热力格（按周、月、年切换）；
- 每月完成次数统计；
- 连续天数随时间变化的折线图；
- 当前连续、最长连续、完成率；
- 一个简单的"习惯强度"评分（近期完成越稳定，分越高）。

#### 3.1.7 笔记与假期（P1）

- 长按某一天可以写当日笔记，说明那天发生了什么；
- 笔记可选附一张照片（P2）；
- "假期模式"：暂时不追踪某个习惯，不产生"失败"记录，也不中断已有连续天数。

#### 3.1.8 归档（P1）

- 不想再追踪但想保留历史的习惯，可以归档；
- 归档习惯不出现在日常列表中，但历史和统计保留，可随时查看或恢复。

---

### 3.2 短期记录（本项目特有，P0）

Streak 没有这部分，是本产品的差异化功能。

#### 3.2.1 添加

- 名称 + 可选截止时间（今天 / 明天 / 本周 / 自定义日期）；
- 可选提醒时间。

#### 3.2.2 完成交互

- 列表项右侧有一个"完成"按钮；
- 点击后该项从亮色变为灰色并加删除线，表示已完成；
- 短暂展示后自动隐藏（或移入"已完成"折叠区，默认折叠）；
- 完成后底部弹出轻提示条，3 秒内可点"撤销"恢复。

#### 3.2.3 历史

- 已完成的短期记录默认隐藏；
- 提供"查看已完成"入口，按日期分组展示（P1）；
- **保留策略：完成后保留 7 天，第 8 天自动彻底清除**，不再占用存储。

---

### 3.3 提醒（P0 核心 / P1 增强）

#### 3.3.1 基础提醒（P0）

- 每个习惯可设置提醒时间（如每天 21:00）；
- 通知内容包含习惯名和一句鼓励语（可自定义）；
- 到点发出提醒，附带震动（可关）；
- 可设置免打扰时段（如 23:00–07:00 不提醒）；
- 提醒的默认形态是"灵动岛式"弹窗（见 3.3.2），系统通知只作为退化方案。

#### 3.3.2 弹窗式提醒——灵动岛风格（P0）

**触发方式（可配置）：**

- 固定间隔：每隔 xx 分钟/小时自动弹一次（如每 30 分钟）；
- 随机间隔：在设定范围内随机取值（如 30–90 分钟之间随机），避免机械感；
- 与固定时间点提醒（如每天 21:00）可并存。

**弹出内容：**

- 从"当天未完成的长期习惯"和"未完成的短期记录"中取出待办条目；
- 没有待办时不弹；
- 同一条待办有冷却时间（默认 30 分钟内不重复弹）；
- 每次最多弹出 N 条（默认 1 条，避免连环轰炸）。

**呈现与交互：**

- 屏幕顶部出现灵动岛式胶囊浮窗（圆角深色胶囊、带应用图标），显示任务名；
- 短期记录额外显示剩余截止时间；
- 浮窗上直接提供操作按钮：**完成打卡 / 稍后提醒 / 关闭**；
- 点浮窗本体进入对应任务详情；
- 点"完成"即打卡，逻辑与列表内打卡完全一致。

**全局设置项：**

- 弹窗提醒总开关；
- 提醒模式：固定间隔 / 随机区间 / 仅定时点；
- 间隔参数（固定值或随机区间）；
- 生效时段（如 08:00–23:00），与免打扰时段合并处理。

**权限与实现约束（Android）：**

- 灵动岛式浮窗需要"显示在其他应用上层"（`SYSTEM_ALERT_WINDOW`）权限，首次使用时引导开启；
- 未授权时自动退化为系统 heads-up 通知（同样可点"完成/稍后"）；
- 后台调度用 AlarmManager / WorkManager；Doze 模式下间隔可能被系统推迟，需提示用户关闭电池优化或接受延迟；
- 随机间隔实现：每次弹出后按区间随机生成下一次触发时间。

#### 3.3.3 通知操作（P1）

参考 Streak，通知上直接放操作按钮：

- **完成**：直接打卡，无需打开 App；
- **稍后提醒**：15 分钟 / 1 小时后再提醒一次；
- 定量习惯可显示"记一笔"快速输入数量。

#### 3.3.4 提醒规则（P1）

- 按习惯的日程决定哪些天提醒（如每周三、周日才提醒）；
- 若当天已完成，则当天不再提醒；
- 每 N 天提醒一次（配合每 N 天的习惯类型）。

#### 3.3.5 桌面小部件（P1/P2）

参考 Streak 提供四类小部件：

| 小部件 | 内容 | 优先级 |
|---|---|---|
| 单个习惯卡 | 一个习惯 + 打卡按钮 | P1 |
| 今日概览 | 今天所有习惯的完成情况 | P1 |
| 统计卡 | 总连续 / 最长连续 / 完成率（可自选字段） | P2 |
| 活动热力格 | 某个习惯的 GitHub 式格子 | P2 |

小部件上可以直接打卡，无需打开 App。

---

### 3.4 专注计时（P2）

参考 Streak 的 Focus 模块，可裁剪为最小集：

- 为需要专注的习惯启动一个计时器（自由计时或绑定习惯与每日目标）；
- 支持番茄钟（25+5 或自定义）；
- 计时中可勾选该习惯的子步骤；
- 每次专注完成后记录历史；
- 每日专注总时长目标（P2）。

白噪音、背景场景、多种钟表样式等先不进 P2 首版，视需要再评估。

---

### 3.5 个性化（P1）

- 亮色 / 暗色主题（跟随系统，可手动切换）；
- 自定义主题色（取色器）；
- 三种整体设计风格可二选一做：Classic（标准）/ Minimal（极简），先做一种，另一种作为后续主题；
- 习惯图标：内置极简图标包或使用任意 emoji；
- 分类标签 + 拖拽排序；
- 个人资料（昵称、头像）仅用于本地展示。

全部完成后撒彩带动效（可做成设置开关）。

---

### 3.6 数据与隐私（P0 备份 / P1 导入 / P2 锁）

| 功能 | 说明 | 优先级 |
|---|---|---|
| 导出备份 | 一键导出为单个 JSON 文件（含习惯、打卡、笔记） | P0 |
| 导入恢复 | 从备份文件恢复 | P0 |
| CSV 导入 | 支持通用的"习惯名 + 日期"CSV | P1 |
| 自动备份 | 每日或每周自动备份到用户指定文件夹 | P1 |
| 云同步 | 已确认要做、暂缓：账号登录 + 数据加密同步，服务方案待定 | P2 |
| 应用锁 | PIN 或指纹（仅本地） | P2 |
| 隐私 | 不做埋点；云同步仅传输必要数据，均加密 | 全程 |

## 4. 界面需求

### 4.1 页面结构（首版）

```text
App
├── 今天（首页）
│   ├── 顶部：日期、问候语、提醒入口
│   ├── 长期习惯列表（卡片：名称、连续天数、7 天圆点、打卡按钮）
│   ├── 短期记录列表（条目：名称、截止、完成按钮）
│   └── 右下角：+ 添加按钮
├── 习惯详情（点卡片进入）
│   ├── 月历视图（已做/未做/未来）
│   ├── 连续天数、完成率
│   ├── 编辑、归档、假期模式
├── 统计（P1）
│   ├── 热力格、月度完成、连续变化折线
├── 设置
│   ├── 主题、颜色、背景
│   ├── 提醒全局设置（免打扰时段）
│   ├── 备份与恢复
│   ├── 关于
```

### 4.2 关键交互

| 场景 | 交互 |
|---|---|
| 今日打卡 | 点击习惯卡片上的"打卡"按钮，一键完成 |
| 撤销打卡 | 再点一次已完成的按钮，或进详情页取消 |
| 短期记录完成 | 点"完成"→ 变灰 → 自动隐藏 → 底部提示条可撤销 |
| 补打卡 | 在习惯详情月历中点任意过去日期 |
| 写笔记 | 长按月历中的某一天 |
| 添加内容 | 首页右下角 + → 选择"长期习惯"或"短期记录" |

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 平台 | Android only（Flutter 实现），不做 iOS/桌面端 |
| 性能 | 冷启动 < 1.5 秒；列表滚动 60fps；打卡响应 < 100ms |
| 数据存储 | 本地 SQLite（Flutter 用 drift/sqflite），不上传任何数据 |
| 权限 | 仅：通知、震动、精确闹钟（用于提醒）；不申请网络权限 |
| 兼容 | Android 8.0+，深色模式适配 |
| 可访问性 | 按钮有语义标签；颜色之外同时用形状/文字区分状态 |
| 多语言 | 首版中文；架构预留多语言 |

## 6. 数据模型（草案）

```text
Habit                 // 长期习惯
- id
- name
- type                // normal | avoid | amount
- unit                // 定量习惯的单位（杯、公里…）
- dailyGoal           // 定量习惯的每日目标
- frequency           // daily | weekly_times | weekdays | every_n_days
- frequencyValue      // 如每周 3 次、每 2 天
- weekdays            // 指定星期几时使用
- reminderTime
- reminderDays        // 哪些天提醒
- color / icon
- archived            // 是否归档
- vacationUntil       // 假期模式结束日期（可空）

CheckIn               // 每天一条
- id
- habitId
- date                // YYYY-MM-DD
- status              // done | failed | skipped
- amount              // 定量习惯当天完成量（可空）
- note                // 当日笔记（可空）

HabitChecklistItem    // 习惯的子步骤（P1）
- id
- habitId
- label
- sortOrder

ShortTask             // 短期记录
- id
- name
- dueDate             // 可空
- reminderTime        // 可空
- done
- completedAt
- hidden              // 完成后自动隐藏标记

ReminderGlobal         // 弹窗提醒全局设置
- enabled
- mode                 // fixed | random | scheduled_only
- intervalMinutes      // 固定间隔（分钟）
- randomMin / randomMax // 随机区间（分钟）
- activeFrom / activeUntil // 生效时段
- maxPerPopup          // 每次最多弹出条数
- cooldownMinutes      // 同一条目冷却时间

FocusSession          // 专注记录（P2）
- id
- habitId             // 可空（自由专注）
- startedAt
- durationMinutes
```

## 7. 里程碑规划

| 阶段 | 内容 | 验收标准（示例） |
|---|---|---|
| M1（MVP） | 添加普通习惯 + 每日打卡 + 连续天数 + 最近 7 天圆点 + 短期记录完整闭环 + 定/随机间隔弹窗提醒 | 用户可以添加"睡前阅读"，每天一键打卡，短期记录做完自动消失；到设定间隔或随机间隔，屏幕顶部弹出灵动岛式浮窗，点"完成"直接打卡 |
| M2 | 月历看板 + 补打卡 + 避免型/定量习惯 + 基础统计 + 主题（亮/暗、主色） | 能在月历上补上周漏掉的打卡；能看到每月完成次数和最长连续 |
| M3 | 通知操作 + 桌面小部件 + 备份/恢复 + 自动备份 | 通知上点"完成"直接打卡；桌面小部件可打卡；换机可完整恢复数据 |
| M4 | 热力格/折线图 + 专注计时 + 导入 + 应用锁 | 年度热力格可浏览；可从 Loop 导入历史数据 |
