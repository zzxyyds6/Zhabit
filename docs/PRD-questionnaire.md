## 核心功能

### 用一句话说,Zhabit 是什么?

> 一个 Android 上的极简、离线优先习惯打卡工具:长期习惯一键打卡看坚持天数,短期记录做完即消失。
_为什么重要:这句话是 PRD 的第一行,也决定后面所有取舍。_

### 你想解决自己的什么具体痛点?举例说明现在的场景。

> 1) 长期习惯(如睡前阅读)坚持了多少天、哪天漏了,没有一个简单的地方能一眼看到,现有 App 要么太重要么 UI 不好看;2) 一次性的小事(买笔记本、回电话)和长期习惯混在一起没地方放,需要一个"做完点一下就消失"的短期记录。
_为什么重要:从真实痛点出发能避免堆功能;没有真实痛点的话项目很难坚持做下去。_

### MVP 必须包含哪些功能?(勾选或补充)

- [x] 习惯打卡(每日完成/跳过)
- [x] 连续打卡天数(streak)
- [x] 提醒/通知
- [ ] 数据统计与图表(放 P1)
- [ ] 习惯分类/标签(放 P1)
- [ ] 备忘/日记附加到打卡(放 P1)
- [x] 数据导出/备份
- [x] 其他:短期记录(一次性待办,做完变灰自动隐藏,完成后保留 7 天自动清除);月历看板(哪天做了/没做,可补打卡);弹窗式提醒(灵动岛风格,按固定/随机间隔自动弹出未完成的长期习惯或短期记录,可直接在弹窗上打卡)

### 明确不做的功能有哪些?(哪怕是常见功能)

> MVP 明确不做:iOS/桌面端/微信小程序;云同步(已确认要做但暂缓,服务方案待定);避免型习惯(如"不熬夜",P2)、定量习惯(P1);统计图表与热力格(P1);桌面小部件(P1);专注计时、应用锁、从 Loop 等其他 App 导入(P2);广告、埋点、账号体系(MVP 不做)。
