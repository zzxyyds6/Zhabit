# 分类标签

技能之间以五个规范的分类角色进行沟通。本文件把这些角色映射到本仓库 issue 追踪器实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue                    |
| `needs-info`               | `needs-info`         | 等待报告者补充信息                        |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整,可交给离线 agent 实现            |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                              |
| `wontfix`                  | `wontfix`            | 不予处理                                  |

当技能提到某个角色(例如"打上 AFK-ready 分类标签")时,使用本表对应的标签字符串。

如实际使用的词汇不同,直接修改"本仓库标签"列即可。
